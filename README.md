# projeto-final-ebac-olist
Análise de dados do e-commerce brasileiro com dados da Olist

## Sobre o projeto
Projeto final do curso de Analista de Dados da EBAC.
Análise exploratória do e-commerce brasileiro utilizando 
os dados públicos da Olist disponíveis no Kaggle.

## Etapas do projeto
- Seleção e carregamento dos dados
- Análise exploratória (EDA)
- Tratamento e limpeza dos dados
- Visualização e dashboard interativo

## Ferramentas utilizadas
- Python (Pandas, Matplotlib, Seaborn)
- Google Colab
- Looker Studio

## Dashboard
[Clique aqui para acessar o dashboard](https://datastudio.google.com/s/mDUQWd0mDBs)

## Principais insights
- A categoria bed_bath_table lidera em receita
- SP concentra a maior parte dos pedidos
- Pedidos com frete mais caro tendem a ter avaliações menores
- Pico de vendas em novembro de 2017 (Black Friday)

## Fonte dos dados
[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
